# 🧮 Calculadora Generation & Caixa Eletrônico

Este projeto é uma aplicação de terminal desenvolvida em Python para simular uma calculadora interativa com menu de opções e operações matemáticas básicas.

## 🚀 Funcionalidades

- **Soma (+)**: Realiza a soma de dois números reais.
- **Subtração (-)**: Subtrai o segundo valor do primeiro.
- **Divisão (/)**: Divide dois números com tratamento de exceção para impedir a divisão por zero.
- **Multiplicação (*)**: Multiplica dois valores.
- **Menu Interativo**: Interface interativa em loop de repetição com opção para encerrar o programa de forma amigável.

## 🛠️ Como Executar o Projeto

1. Certifique-se de ter o Python 3 instalado no seu ambiente.
2. Execute a primeira célula para definir as funções das operações matemáticas.
3. Execute a segunda célula para iniciar o menu interativo no console.
4. Escolha uma das opções numéricas (de 1 a 5) para realizar a operação desejada ou encerrar o programa.

## 📁 Estrutura de Código

- `soma(saldo)`: Recebe os números e retorna a soma.
- `sub(saldo)`: Recebe os números e retorna a diferença.
- `div(saldo)`: Contém lógica protetiva contra divisões nulas.
- `mult(saldo)`: Efetua o produto dos números.
- `while True`: Loop principal responsável por manter o menu ativo e capturar as interações do usuário.
